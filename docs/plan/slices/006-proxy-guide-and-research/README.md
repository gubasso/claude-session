# Proxy guide and research

## Goal

Revalidate externally owned facts and give users an executable proxy-integration guide.

## Appetite

1 implementation session.

## Core

Every due registry entry is checked and the guide demonstrates the inherited proxy seam without inventing a wrapper feature.

## In scope

- Extend existing prior-art comparisons.
- Update owning pages for measured drift.
- Add and index one concrete proxy integration guide.

## Out of scope

- A second prior-art document.
- Compression, rewriting, routing, or a wrapper-owned environment injection surface.

## Acceptance

- When a registry entry is due, the maintainer shall execute every recorded revalidation procedure and update its owner for measured drift.
- When prior art is extended, the page shall distinguish inspected facts from inference and cite public sources.
- When the proxy guide is followed, the child shall inherit the proxy endpoint without a wrapper-specific injection feature.

## Rabbit holes

- Implementing the proxy itself; escape: document the inherited environment seam only.
- Broad competitive surveys; escape: add only inspected projects that inform a present boundary.
